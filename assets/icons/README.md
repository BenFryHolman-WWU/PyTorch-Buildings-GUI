# UI Icons

Drop toolbar and component icons in this folder. The PyQt6 UI looks here first, then falls back to files in `assets/`.

Supported formats: `.svg`, `.png`, `.jpg`, `.jpeg`.

Recommended names:

- `save.svg`
- `load.svg`
- `connection.svg`
- `edit.svg`
- `delete.svg`
- `delete_area.svg`
- `envelope.svg`
- `rtu.svg`
- `vav_box.svg`
- `solar_gains.svg`

Restart the app after adding or replacing icon files.
